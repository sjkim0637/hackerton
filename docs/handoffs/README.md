# Handoff 문서 안내

다른 팀이나 작업자가 이어서 일해야 할 때 필요한 정보를 이 디렉터리에 남긴다. 간단한 인계는 Workstream의 `Notes for Other Teams`와 `Next`에 적고, 중요한 인계는 별도 문서로 작성한다.

## Template

```markdown
# Handoff

## From

GitHub ID

## To

GitHub ID 또는 Integration

## Workstream

관련 작업

## Completed

완료한 내용

## Important Files

중요 파일

## Decisions

주요 결정

## Constraints

주의사항

## Known Issues

알려진 문제

## Next

다음 작업

## Relevant Commits

관련 Commit
```

후속 담당자가 이전 대화를 보지 않아도 시작할 수 있을 정도로 현재 상태와 다음 행동을 명확히 쓴다.
