# Architecture 문서 안내

이 디렉터리는 팀이 채택한 시스템 구조를 설명한다. 현재는 기술 Stack과 실제 Architecture를 결정하지 않았으므로 안내 문서만 둔다.

향후 다음 내용을 관리한다.

- System Architecture와 주요 Component
- Component 사이의 Interface
- Data Flow
- Deployment 구조
- External Integration
- Dependency 관계와 제약

아이디어나 비교 중인 구조는 Workstream에 기록하고, 중요한 선택과 이유는 `docs/decisions/`에 남긴다. 이곳에는 현재 채택된 구조를 비개발자도 이해할 수 있게 설명한다.
