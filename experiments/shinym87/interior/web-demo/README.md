# ROOMFIT 3D 웹 데모

`integration-interior-demo`의 배포 소스입니다. 정적 사이트이며 `dist/index.html`을 직접 실행하거나 정적 웹 서버로 제공할 수 있습니다.

## 현재 기능

- 실제 제품 브로셔 선택 및 실측 비율 배치
- 배치 가구 드래그 이동, 좌우·상하 회전, 충돌 방지
- 업로드 거실 사진 기반 편집
- 사진 속 기존 소파·탁자·TV 선택 및 개별 삭제
- 기존 가구 삭제 영역의 AI 복원 레이어 적용

## 주요 파일

- `dist/index.html`: 화면과 전체 상호작용
- `dist/room-uploaded.png`: 기본 거실 사진
- `dist/restorations/`: 기존 가구 삭제 시 사용하는 복원 레이어
- `dist/products/`: 배치 가능한 실제 제품 이미지
