## 시연 시나리오 (확정)

거실, 정면 벽에 TV 가 걸려 있는 상황. 하나의 흐름만 끝까지 보여준다.

1. 거실을 카메라로 스캔 → 벽/바닥 평면 인식(격자 표시)
2. TV 를 탭해 선택 → 대상 영역(사각형) 표시
3. `삭제` 실행
   - 그 시점의 대표 이미지(키프레임) + 카메라/평면 메타 저장
   - 외부 AI 에 "TV 제거 + 벽 복원" 1회 요청
   - 복원된 벽 이미지를 그 벽 평면에 사각형(quad)으로 고정
4. 삭제된 TV 를 다른 벽으로 재배치 (반투명 프록시 + 드래그 이동 / 핀치 크기)
5. 새 소파를 카탈로그에서 골라 빈 바닥에 배치
6. `배경 표시` 토글로 변경 전 / 변경 후를 비교

핵심 경험: **"내 실제 거실을 보면서 현실 공간을 직접 편집한다."**

## MVP 범위 (확정)

포함
- 카메라 미리보기 + 수평/수직 평면 인식
- 사물 1종(TV) 탭 선택 + 축 정렬 사각형(bbox) 영역 지정
- A 방식(외부 AI 이미지 편집 API) 1회 호출로 삭제 + 빈 벽 복원
- 복원 결과 이미지를 벽 평면에 quad 로 공간 고정
- 반투명 프록시로 가구 이동/크기 조절 (기존 `interior` 앱 로직 재사용)
- 새 가구 1종(소파) 카탈로그 배치
- 변경 전/후 비교 오버레이

제외 (이후 PHASE)
- 다중 사물 동시 편집, 정밀 세그멘테이션 마스크, 그림자 생성/제거
- 가구 회전, 벽지/벽 색상/바닥 재질 변경
- 카메라 이동 중 재투영(Reprojection) 고도화 → PHASE 3
- 로그인 / 결제 / 실제 상품 연동
- B(경량 모델) / C(자체 엔진) → PHASE 6 / 7

## PHASE 1 진입 조건

설계서대로 "품질보다 처음부터 끝까지 한 번 연결"을 목표로 한다.

```text
카메라 → 대표 이미지 → 서버 → AI 처리 → 변경 이미지 → 스마트폰
```

이 흐름이 한 번이라도 성공하면 PHASE 1 완료로 본다. 결과가 어색해도 괜찮다.
