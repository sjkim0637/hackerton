### 핵심 병목

- **제거 병목:** 현재 가구가 가린 공간을 볼 수 없습니다.
- **선택 병목:** 사각 bbox 안에 다른 물체가 겹치면 AI가 대상을 정확히 분리하기 어렵습니다.
- **정합 병목:** 2D AI 결과를 실제 3D 벽 위치에 안정적으로 유지해야 합니다.
- **비교 병목:** 기존 가구와 새 가구의 여러 배치를 저장하고 되돌릴 수 있어야 합니다.
- **신뢰 병목:** 복원 결과의 색감·해상도·경계·원근이 자연스러워야 합니다.

## 6. 💡 최종 선택된 아이디어

### 최종 아이디어

**MISO ROOMSHIFT — AI 사물 제거, AR 재배치와 공간 상태 관리를 연결한 공간 리디자인 서비스**

### 선택한 이유

- 새 가구를 올려보는 기존 AR 경험을 넘어, 기존 가구 제거부터 재배치까지 연결합니다.
- AI는 가려진 공간 복원에, AR은 실제 위치·크기·이동 검증에 집중합니다.
- PHASE 3~5에서 결과 신뢰성, 배치 저장·복원·Undo, 새 가구 Catalog까지 실제 코드로 확장했습니다.
- TV 제거 하나로 시작해 기존 가구 이동과 신규 가구 배치까지 2분 시연으로 보여 줄 수 있습니다.

### PHASE 1~5 핵심 기능

| PHASE | 구현 내용 | 사용자가 얻는 가치 |
|---|---|---|
| 1. 전체 연결 | 촬영, bbox, Keyframe, Gemini/Mock 제거, Job Polling, 전후 비교 | 실제 공간 편집의 전체 흐름 체험 |
| 2. 선택·안정성 | TV/소파/테이블/의자/선반/소품 선택, 겹침 경고, 사물별 Prompt, 재시도·캐시·비용 로그 | 대상을 더 명확히 지정하고 실패·중복 호출 감소 |
| 3. 결과 품질 | Quad EMA 스무딩, 추적 손실 위치 유지, 경계 페이드, 색감 보정, 이상 감지, 결과 버전 관리 | 카메라 이동 중 안정성과 결과 신뢰 향상 |
| 4. 기존 가구 재배치 | 제거 사물 Crop, 드래그·핀치·회전, 벽/바닥 맞춤, 원위치, Placement 저장·복원·Undo | 실제 가구를 옮기지 않고 여러 위치 시험 |
| 5. 새 가구 추가 | 서버 Catalog, Thumbnail, 새 가구 AR 배치, Placement 저장·복원, 즉시 드래그 UX | 기존 가구와 새 가구를 하나의 공간에서 구성 |

### 기대효과

- 가구를 실제로 옮기기 전 빈 공간과 배치안을 확인합니다.
- 기존 가구와 새 가구를 같은 조작 방식으로 이동·회전·크기 조절합니다.
- 배치를 서버에 저장하고 다시 복원하거나 Undo할 수 있습니다.
- AI 편집 결과를 버전별로 보존해 여러 시도를 비교할 수 있습니다.
- 온라인 구매와 공간 변경에 필요한 시각적 판단 근거를 강화합니다.

### AI가 도울 일

- 선택된 가구·그림자·케이블 등 제거 대상의 시각 요소를 제거합니다.
- 주변 벽·바닥의 색상, 질감, 원근을 참고해 가려진 공간을 복원합니다.
- 사물 종류와 공간 조건에 맞는 편집 Prompt를 구성합니다.

### MISO 구성과 역할

| 구성 | 역할 | 현재 상태 |
|---|---|---|
| MISO 대화/입력 | “TV를 지우고 소파를 추가해 줘” 같은 의도와 대상 확인 | 설계 |
| MISO Workflow | Scene → Keyframe → Remove Job → Result → Placement API 순서 조율 | 설계 |
| MISO Prompt Builder | 사물 종류, bbox, 주변 표면에 맞는 편집 지시 구성 | 서버 Prompt 로직 구현, MISO 연결 대기 |
| FastAPI Tool Layer | Scene, Result, Catalog, Placement, Undo API 제공 | 구현 |
| Gemini Provider | 실제 이미지의 사물 제거와 배경 복원 | 구현 및 TV 실사진 검증 |
| Quality Guard | 원본 해상도 유지, 색감 보정, 이상 감지, 재시도 | 구현 및 테스트 |
| 사용자 안내 | 처리 상태, 오류, 겹침 경고, 다음 행동 설명 | 앱 일부 구현, MISO 대화 연결 대기 |

> 해커톤에서 MISO를 주 AI 도구로 사용하려면 FastAPI Endpoint를 MISO Tool로 등록하고, MISO가 사용자의 의도 확인·Workflow 조율·결과 설명을 담당하도록 연결해야 합니다. 현재 브랜치에는 FastAPI와 Gemini Provider까지 구현돼 있으며 MISO 실제 연결은 아직 완료되지 않았습니다.

### 전체 작동 흐름

1. 사용자가 MISO 또는 앱에서 공간 편집 목표를 입력합니다.
2. Android 앱이 벽·바닥을 인식하고 Scene을 생성합니다.
3. 사용자가 사물 종류와 bbox를 지정합니다. 큰 bbox에는 겹침 경고를 표시합니다.
4. 앱이 Keyframe과 Camera·Plane Metadata를 FastAPI에 전송합니다.
5. MISO Workflow 또는 앱이 Remove Object Job을 실행합니다.
6. 서버가 중복 요청과 호출 상한을 확인한 뒤 사물별 Prompt와 Mask를 구성합니다.
7. Gemini가 사물을 제거하고 배경을 복원합니다. 일시적 오류는 1회 재시도합니다.
8. 서버가 원본 해상도 유지, 색감 보정과 이상 결과 검사를 수행하고 버전을 저장합니다.
9. 앱이 결과를 Polling하고 벽 Quad에 스무딩·경계 Fade와 함께 표시합니다.
10. 제거한 사물이 즉시 Marker로 나타나며 사용자가 드래그·핀치·회전합니다.
11. 사용자는 Catalog에서 새 가구를 골라 벽 또는 바닥에 배치합니다.
12. 모든 Placement가 서버에 저장되며 복원·Undo·원위치 기능으로 여러 배치를 비교합니다.

### 기술 테스트에서 얻은 주요 피드백

- bbox 안에 다른 가구가 겹치면 소파 같은 비정형 사물 제거 품질이 크게 떨어집니다.

- 카메라 격자와 특징점 Overlay가 Keyframe에 들어가면 AI 편집 결과를 방해합니다.
- AI 결과를 바로 표시하면 색감·경계·위치 흔들림 때문에 합성처럼 보일 수 있습니다.
- 사용자가 가구를 옮기기 위해 별도 버튼과 Tap 단계를 거치는 것보다, 제거 직후 Marker를 바로 드래그하는 방식이 자연스럽습니다.
- 여러 편집과 배치가 생기면 Result Version과 Placement History가 반드시 필요합니다.

## 12. 🚀 스토리텔링(솔루션 설명서)

### 문제의 시작

거실의 TV를 다른 벽으로 옮기고 새 소파를 놓으려 해도, 현재 TV가 사라진 뒤의 벽과 새 배치의 동선을 정확히 상상하기 어렵습니다. 기존 AR 서비스는 새 가구를 올려보는 데 강점이 있지만, 사용자의 집에 이미 있는 가구를 자연스럽게 없애고 다시 활용하는 전체 과정은 여전히 단절돼 있습니다.

### 우리의 관점

우리는 공간 편집의 핵심을 “새 가구를 보여 주는 것”이 아니라 **기존 공간을 비우고, 기존 가구와 새 가구를 자유롭게 다시 구성하며, 그 상태를 안전하게 비교하는 것**으로 정의했습니다.

### 해결 방법

MISO ROOMSHIFT는 사용자가 지우려는 사물의 종류와 영역을 확인하고, FastAPI를 통해 Gemini 이미지 편집을 실행합니다. Gemini는 사물과 그림자·케이블을 제거하고 가려진 벽을 복원합니다. 서버는 결과 해상도를 유지하고 색감을 맞추며, 편집 영역 밖이 지나치게 달라진 결과를 감지합니다. 결과는 버전별로 저장됩니다.

Android 앱은 결과를 실제 벽 Quad에 표시합니다. EMA 스무딩과 경계 Fade를 적용해 카메라 이동 중 시각적 흔들림을 줄입니다. 제거한 가구는 즉시 Marker로 다시 나타나 사용자가 끌어서 다른 위치로 옮기고, 크기와 회전을 조절할 수 있습니다. 새 가구는 서버 Catalog에서 선택해 같은 공간에 배치합니다. 모든 Placement는 서버에 저장되며 복원과 Undo가 가능합니다.

### MISO의 역할

MISO는 단순한 안내 Chatbot이 아니라 공간 편집 Workflow의 조율자입니다. 사용자의 목표와 제거 대상을 확인하고, Scene·Keyframe·Remove Job·Result·Catalog·Placement API를 올바른 순서로 실행합니다. 처리 중에는 상태를 설명하고, 겹침·품질 이상·AI 오류가 발생하면 재선택이나 재시도를 안내합니다. 이미지 Pixel 편집은 Gemini가 맡고, MISO는 사용자 의도와 여러 Tool을 하나의 경험으로 연결합니다.

### PHASE 5까지 만든 결과

- PHASE 1: Android → FastAPI → Gemini/Mock → Android 전체 연결
- PHASE 2: 다양한 사물, Prompt, 겹침 경고, 중복 방지, 재시도와 비용 관리
- PHASE 3: 결과 정합·경계·색감·이상 감지·버전 관리
- PHASE 4: 제거한 기존 가구의 재배치·회전·크기·저장·복원·Undo
- PHASE 5: 새 가구 Catalog·Thumbnail·AR 배치·상태 저장, 즉시 드래그 UX

서버에는 47개의 테스트 함수가 있고, 전체 HTTP Workflow 13단계를 통과했습니다. 실제 거실 사진에서는 Gemini로 TV·사운드바·케이블을 제거하고 벽을 자연스럽게 복원했으며 4032×3024 원본 해상도를 유지했습니다. Android Debug APK 빌드도 성공했습니다.

### 아직 검증해야 할 것

현재 가장 중요한 남은 검증은 Android 실기기에서의 전체 E2E입니다. 실제 카메라를 움직일 때 Anchor와 Marker가 안정적인지, 사용자가 드래그·핀치·회전·복원·Undo를 쉽게 이해하는지 확인해야 합니다. 또한 MISO Tool 연결과 실제 사용자 인터뷰·사용성 테스트, 시연 영상이 필요합니다.

### 기대하는 변화

ROOMSHIFT가 제공하는 핵심 가치는 “멋진 인테리어 이미지를 생성했다”가 아닙니다. 사용자가 **무거운 가구를 옮기기 전에 자신의 공간을 직접 비우고 다시 구성해 보았다**고 느끼게 하는 것입니다. 이를 통해 가구 구매와 재배치의 시행착오를 줄이고, 가족이 같은 화면을 보며 더 빠르게 합의할 수 있습니다.

### 최종 메시지

> **MISO ROOMSHIFT는 가구를 사기 전에 보여 주는 서비스를 넘어, 공간을 바꾸기 전에 직접 편집하고 비교하게 하는 서비스입니다.**
