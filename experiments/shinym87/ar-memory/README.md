# 단지 추억 공유 소셜 AR — 웹 프로토타입

아파트 단지 입주민 전용 "추억 공유 소셜 AR"의 뼈대 프로토타입이다. 실제 AR Glass가 없는 상태에서, 단지 배치도 이미지(SVG) 위에 핀을 찍고 클릭하면 그 장소에 쌓인 게시물을 시간순으로 볼 수 있는 방식으로 핵심 컨셉을 먼저 검증한다.

## 핵심 컨셉

- CCTV처럼 자동 기록되는 것이 아니라, 입주민이 "이 순간을 남기고 싶다"고 직접 선택했을 때만 게시물이 생성된다.
- 촬영 장소와 게시 장소가 항상 같다 (단지 안에서 찍은 것을 그 자리에 게시).
- 같은 장소에 여러 시점의 기록이 쌓여 그 장소의 "시간 흐름"을 볼 수 있다.

## 실행 방법

```bash
npm install
npm run dev
```

`http://localhost:5173`(포트는 콘솔 출력 확인)로 접속한다. 별도 Backend/DB 없이 브라우저의 `localStorage`에 데이터가 저장되는 클라이언트 전용 구현이다.

```bash
npm run build   # 타입 체크 + 프로덕션 빌드
```

## 기술 스택

- React 19 + TypeScript + Vite
- 상태 관리: React Context (`src/state/AppContext.tsx`) + `localStorage` 영속화
- 별도 Backend/DB 없음 — 사진·영상은 `FileReader`로 Base64 Data URL 변환 후 `localStorage`에 저장
- 지도는 실제 지도 API 대신 인라인 SVG로 그린 단지 배치도(장식용 건물·산책로 포함)를 사용

이 기술 선택은 이 실험(Workstream)의 검증 대상이며, 프로젝트 전체 표준으로 간주하지 않는다. 자세한 내용은 `docs/workstreams/ar-memory.md` 참고.

## 구현된 기능

### 화면
1. **단지 지도** (`MapPage` + `SiteMap`): 게시물이 있는 5개 지점(중앙 벚꽃길, 어린이 놀이터, 공동 텃밭, 반려동물 산책로, 실개천 정자)에 핀 표시. 카테고리별 색상/이모지, 게시물 개수 배지.
2. **지점 타임라인** (`SpotTimeline`): 핀 클릭 시 해당 지점의 게시물을 시간순으로 나열. 같은 장소·다른 시점 기록을 비교하는 느낌을 주도록 세로 타임라인 UI로 표시.
3. **게시물 등록** (`PostForm`): 사진/영상 업로드, 카테고리 선택(계절 풍경/아이 성장/텃밭·화단/반려동물), 지도 클릭으로 위치(지점) 선택, 공개범위 선택(기본값: 이웃 공개).
4. **계정 전환 + 이웃 관리** (`AccountPage`): 테스트 계정 3개 전환, 이웃 맺기/해제.

### 소셜 로직
- 이웃 맺기는 편도(팔로우形) 관계다. 테스트 계정 3개는 서로 다른 이웃 관계를 갖도록 시드되어 있어(김민준→이서연, 이서연→김민준·박도윤, 박도윤→이서연), 계정을 바꾸면 같은 지점이라도 보이는 게시물이 달라지는 것을 확인할 수 있다.
- 지점 타임라인 노출 규칙(`AppContext.getSpotPosts`):
  - 내 글, 내가 이웃 맺은 사람의 글: 공개범위와 무관하게 기본 노출.
  - 이웃이 아닌 사람의 "단지 전체 공개" 글: "더보기"로 분리 노출.
  - 이웃이 아닌 사람의 "이웃 공개" 글: 노출하지 않음.
- 좋아요/댓글은 게시물 카드에서 바로 가능하다.

### 시드 데이터
- 테스트 계정 3개(`src/data/seed.ts`)와 5개 지점에 걸친 15개 샘플 게시물을 기본 제공한다. 벚꽃길의 봄→여름→가을→겨울, 놀이터의 아이 성장, 텃밭의 심기→자라기→수확처럼 "같은 장소·다른 시점"을 바로 체감할 수 있도록 구성했다.
- 시드 게시물은 실제 파일이 없으므로 카테고리 색상의 그라디언트 placeholder(`MediaPlaceholder`)로 표시되고, 사용자가 직접 등록한 게시물은 실제 업로드 이미지/영상이 표시된다.

## 알려진 제약 (프로토타입 범위)

- 실제 인증 없음 — 테스트 계정 전환으로 로그인을 대신한다.
- Backend/DB 없음 — 모든 데이터는 브라우저 `localStorage`에만 저장되고 기기/브라우저 간 공유되지 않는다.
- 위치는 GPS/실제 지도 좌표가 아니라, 미리 정의한 5개 지점 중 선택하는 방식이다.
- 업로드 용량 제한, 이미지 압축 등은 처리하지 않는다.
- 실제 AR(카메라 오버레이, 6DoF)은 다루지 않는다 — 지도 기반 화면으로 컨셉만 검증한다.
