# PHASE 0 — 기본 설계 및 규칙 확정

## 결과

PHASE 0 문서화를 완료했다. 다음 단계에서는 품질을 높이기 전에 카메라에서 시작해 서버와 AI를 거쳐 결과가 앱에 돌아오는 전체 흐름을 한 번 연결한다.

## 시연 시나리오

초기 시연은 거실의 TV 제거와 재배치를 중심으로 한다.

1. 사용자가 스마트폰으로 거실을 촬영한다.
2. 앱이 벽과 바닥 평면을 인식한다.
3. 사용자가 TV 영역을 선택한다.
4. `삭제`를 누르면 대표 이미지와 선택 영역이 서버로 전송된다.
5. 외부 AI가 TV와 그림자를 제거하고 가려진 벽을 복원한다.
6. 복원 결과를 실제 벽 위치에 표시한다.
7. 기존 TV를 다른 벽으로 옮긴다.
8. 카탈로그에서 새 소파를 골라 바닥에 배치한다.
9. 변경 전과 변경 후를 비교한다.

이 시나리오는 초기 기준이며 이후 확장하거나 변경할 수 있다.

## MVP 포함 범위

- Android 카메라 화면
- ARCore 실행 환경
- 벽·바닥 평면 인식
- TV 영역을 사각형으로 선택
- 대표 이미지 캡처
- 외부 AI를 통한 TV 제거와 벽 복원
- 결과 이미지를 벽 평면에 표시
- 반투명 가구 배치·이동·크기 조절
- TV 재배치
- 새 소파 1종 배치
- 변경 전·후 비교

## 초기 MVP 제외 범위

- 정확한 자동 사물 인식
- 여러 가구 동시 편집
- 고품질 3D 가구 모델
- 정교한 그림자 생성
- 가구 충돌 처리
- 벽지·벽 색상·바닥 재질 변경
- 자체 AI 모델 학습
- 로그인·결제·실제 상품 연동
- B 방식 경량 모델과 C 방식 자체 복원 엔진

제외 기능은 폐기한 것이 아니며 PHASE 2 이후 일정과 검증 결과에 따라 추가한다.
