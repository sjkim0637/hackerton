# AR 라이프 — 클릭형 웹 프로토타입

집과 아파트 단지의 생활 정보를 AR 마커 형태로 발견하고 즉시 실행하는 모바일형 웹 프로토타입이다.

## 핵심 경험

- 단지 화면 위에서 내 차, 택배함, 우리 집 에너지, 커뮤니티 시설 마커 확인
- AR 탐색과 목록 보기 전환
- 마커 선택에 따라 상세 정보와 실행 버튼 변경
- 길 안내, 택배 수령, 대기전력 끄기, 시설 확인 흐름 체험

## 실행

별도 설치 없이 `index.html`을 브라우저로 열면 된다.
